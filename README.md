# 使用方法及实践过程
## Unity2D景深摄像机使用方法
1.下载ParallaxCamera.cs和Parallaxlayer.cs
2.在unity中将ParallaxCamera组件添加到场景中的主摄像机中，创建一个玩家对象（如Player），将ParallaxCamera的Target设置为玩家对象，按照需求调整其他参数。
3.为场景中的远景，中景和近景对象添加Parallaxlayer组件，分别在Inspector面板中为其调整速度参数
 默认：远景 0.6，0.6 
      中景 0.3 0.3
      近景 0.1 0.1
# 实践流程
在git官网本地安装了git，并用VScode进行git可视化管理。在VScode中，点击初始化仓库，即可创建本地仓库。其中还有添加远程仓库，上传文件等功能。
此后，我在本仓库上传简单的Unity脚本以及README文件。
# 遇到的问题
1.对于github的仓库功能不了解，在网上查询视频和询问AI后，才弄清每个功能的作用。
2.git的命令行操作不够方便，不容易上手，使用VSCode的可视化操作解决了这一问题
# Git学习心得
使用git仓库后，发现有很多优点。代码写崩了或者误删文件，随时可以回到之前的任何一个版本，不用从头重写。开发新功能时开个“分支”，测试好了再合并到主代码里，不会影响正在运行的稳定版本。谁在什么时间改了哪一行代码，记录清清楚楚，出了问题能精准定位。
